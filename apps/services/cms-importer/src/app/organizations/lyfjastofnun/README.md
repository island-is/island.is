# Lyfjastofnun Imports

Imports published material from lyfjastofnun.is. Instructions, lists and forms
are scraped from WordPress pages into generic list items; English titles come
from the corresponding pages on ima.is. Documents are uploaded as Contentful
assets and external URLs become `linkUrl` entries.

These imports are disabled pending testing. They have no Nx targets or CLI
routes. The implementation remains in `jobs/` for future validation.

See [News import](jobs/news/README.md) for the image requirements.
