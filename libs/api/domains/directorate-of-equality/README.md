# api-domains-directorate-of-equality

GraphQL domain for the company-only My Pages module "Jafnrétti á vinnumarkaði" (Jafnréttisstofa): submitted equality plans and salary reports, read through `@island.is/clients/directorate-of-equality`.

The application forms use `api-domains-directorate-of-equality-application` instead.

## Running unit tests

Run `nx test api-domains-directorate-of-equality` to execute the unit tests via [Jest](https://jestjs.io).
