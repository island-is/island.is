# Frontend (UI)

Sources: [Definition of done](https://docs.devland.is/development/definition-of-done.md), [Digital Iceland policies](https://island.is/en/o/digital-iceland/policies-terms-and-guidelines-digital-iceland)

- **UI-1** No hard-coded user-facing strings. Use the localization lib / Contentful messages with both Icelandic and English values.
- **UI-2** WCAG 2.1 AA minimum: semantic headings, lists and landmarks; labelled inputs; full keyboard support; no focus traps; visible focus; ARIA only where HTML falls short.
- **UI-3** Use `@island.is/island-ui` components and tokens before custom styling.
- **UI-4** Support browsers with more than 1% usage in Iceland.
- **UI-5** Reusable UI components get Storybook stories.
